# Asymmetries in Peer Effects

**Aristide Houndetoungan and Mathieu Lambotte**

This folder contains all replication files.

- `0.Example-Allocation.R` produces the treatment assignment illustration in Figure 1.
- `1.MonteCarlo.R` produces the simulation results presented in Table 1.
- `2.AddHealth.data.R` prepares the data for analysis. It extracts data from the raw Add Health datasets, performs data cleaning, and saves the cleaned datasets. It also produces the data summary in Table C.1 in Appendix C.
- `3.AddHealth.Estimation.R` uses the cleaned data to estimate the symmetric and asymmetric models. It produces the results shown in Table 2 and Tables C.2 and C.3 in Appendix C.
- `4.AddHealth.Policy.R` reproduces the policy intervention results presented in Figure 2.
